# Sources

Fetched 2026-10-23.

## Foundational
- Palermo, The Onion Architecture, parts 1-3 (2008): https://jeffreypalermo.com/2008/07/the-onion-architecture-part-1/ , https://jeffreypalermo.com/2008/07/the-onion-architecture-part-2/ , https://jeffreypalermo.com/2008/08/the-onion-architecture-part-3/
- R. Martin, The Clean Architecture (2012): https://blog.cleancoder.com/uncle-bob/2012/08/13/the-clean-architecture.html
- Cockburn, Hexagonal Architecture: https://alistair.cockburn.us/hexagonal-architecture/
- Fowler, Anemic Domain Model: https://martinfowler.com/bliki/AnemicDomainModel.html
- Fowler, Presentation Domain Data Layering (split by domain first, layer inside): https://martinfowler.com/bliki/PresentationDomainDataLayering.html

## DDD applicability
- Microsoft, DDD-oriented microservice (apply DDD to complex rules; CRUD needs simpler approaches): https://learn.microsoft.com/en-us/dotnet/architecture/microservices/microservice-ddd-cqrs-patterns/ddd-oriented-microservice
- Domain-Driven Hexagon (itself notes full separation is overkill for simple CRUD): https://github.com/Sairyss/domain-driven-hexagon
- Khorikov, Domain model purity, completeness, and performance: https://enterprisecraftsmanship.com/posts/domain-model-purity-completeness/

## Caveats
- Eric Evans' and Vaughn Vernon's DDD books were not fetched; terminology relies on the sources above.
- GitHub repository dates were not visible.
- The glossary is derived from code, not from a product specification.
